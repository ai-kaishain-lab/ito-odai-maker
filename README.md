# 数字で語れ！お題メーカー

協力型カードゲーム「ito」で遊ぶときに使える、お題ジェネレーター＆数字配りツールです（非公式のファンツール）。

## できること

- **お題をつくる**：オリジナルのお題 約70個（定番／食べ物／会社員あるある／AI・テック／想像力／人間関係）。各お題に「1＝○○／100＝○○」の目安つき
- **ミックス**：「場面 × ものさし」の組み合わせで約530通りのお題を自動生成（例：会社にあるものの背徳感）
- **数字を配る**：2〜10人に1〜100の数字を重複なしで配布。タップで自分の数字だけ確認、最後に「答え合わせ」で小さい順に表示
- **コピー**：お題と目安をコピーしてSNSに投稿できる

## 使い方

`index.html` をブラウザで開くだけ。インストール不要、1ファイルで動きます。

GitHub Pages を有効にすると、スマホからURLで開けます。

## 注意

- 本ツールは非公式です。「ito」の権利者とは関係ありません。
- 収録しているお題はすべてオリジナルで、公式カードの文言は使用していません。
